What this changed in the benchmark

    
Before this step existed, 10 of the 16 BugsInPy bugs it now trims overflowed the Agent SDK tool-result limit, and the reviewer got an error instead of a context. After it, none did, at the same cost. Bugs found did not change: without a context the reviewer explored the code with its own tools and did about as well, and with the trimmed context it sometimes stopped too early (the thefuck#7 example is one such case). Details in bench_impact/RESULTS.md.
